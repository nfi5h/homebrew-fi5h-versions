# Nfi5h Fi5h-versions

## How do I install these formulae?

`brew install nfi5h/fi5h-versions/<formula>`

Or `brew tap nfi5h/fi5h-versions` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nfi5h/fi5h-versions"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
